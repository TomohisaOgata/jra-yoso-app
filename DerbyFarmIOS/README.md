# ダービー牧場 iOS (SwiftUI)

既存の jra-yoso-app リポジトリ内に独立した iOS ゲームのソースを置いています。競馬予想アプリのファイルは変更しません。

## 内容
- 愛馬の育成、なでなで、調教、休養
- スピード・パワー・スタミナの三すくみ
- 2026年の主要JRA GI開催日を参考にしたゲーム内レース
- UserDefaultsによるローカル保存

## ビルド
MacのXcodeで新規 iOS App (SwiftUI / iOS 17+) を作成し、DerbyFarmApp.swift と ContentView.swift を追加してビルドしてください。iPhoneへのインストールにはAppleの署名が必要です。
